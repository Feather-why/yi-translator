Building a faster browser translation extension

This page tests the full guide to local translation. Visit https://example.org/models for the model list, or run llama-server -ngl 99 on your laptop.

The translated text should keep the same font and color as the original paragraph. Links must stay clickable after translation.

Speed matters. The first screen should appear in under half a second! Quality matters too: the local model must beat classic machine translation.

  • Fast mode uses the free machine translation pool.
  • Accurate mode uses the 7B model on the desktop.
  • Combined mode shows the fast result first, then overwrites it.
