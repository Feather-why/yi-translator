# Yi 0.2.14

修复动态菜单和快速切换翻译时可复现的卡顿，并支持拖动图片上的翻译按钮。

- 展开下拉菜单时，每个新段落只生成一份译文。菜单关闭后复用原节点，再次打开仍可翻译。快速开启和还原翻译时，只有最后一次操作生效。
- 网页清理浮层时，悬浮球会延迟恢复，浏览器可以继续响应点击。长标识符的链接识别和含大量软换行的段落扫描也已提速。
- 图片右上角有网站按钮时，翻译浮球会尝试其他可用角落。按住浮球拖到图片的其他位置，松手即可。位置随图片缩放，并保留到本页关闭或刷新。单击仍可翻译或切换原图。

下载 `translate-ext-0.2.14-chrome.zip`，解压到原来加载扩展的目录，在扩展管理页重新加载并刷新网页即可使用。Windows x64 本地模型助手可沿用已有安装。

详细复现与验收记录见[交接文档第 51 节](HANDOFF-BACKEND.md#51-动态菜单与快速点击卡顿图片翻译按钮拖动)。
