# 第 34.3 节：缺失原子占位符与 Unicode 保留

日期：2026-11-04。纯恢复实现为 `src/backend/placeholder-atoms.ts`，对外函数 `restoreMissingAtoms(source, target): string | undefined`。本文件记录算法与独立合约；生产 Core 接线、真实模型和全量验证由总集成另记。

## 恢复规则

恢复对象仅为原文中已经存在、译文中遗漏的 `<xN/>`。函数保留模型完整译文，插回原文对应 token；不翻译原子内部内容，不重新生成整段，不调用模型。

1. 先解析原文、译文的分组树。成对 `g` 必须全部存在且正确闭合，编号唯一，原子或分组的父节点必须与原文一致；已知分组可以整体换序。
2. 对每个缺失 `x`，只在它原来的父组范围中定位。最近的现存同级组或原子作为左右边界；不跨越现存链接/强调节点。如果两个边界在译文中颠倒，或边界间夹进了其他重排的结构节点，返回 `undefined`，保留原有严格重试/降级。
3. 在这段无结构标记的文字内，以原文去掉缺失原子后的字符相对位置映射到译文。原文计数使用 Unicode 码点，译文采用 `Intl.Segmenter` 字素边界和最近的词边界。开头/结尾原子保持相应位置；连续多个原子按源文顺序恢复。
4. 最后仍调用生产 `validTranslation` 校验数量、嵌套和父子关系，只有通过才返回。输出去掉新插入 token 后，与原始模型译文的字符完全相同。

缺少 `g`、损坏/未知标记、重复编号、已有原子父组错位、转义为 `&lt;xN/&gt;` 的标记均不作为“单纯遗漏”修复。源码含不在协议内的原始尖括号文本时也保守返回 `undefined`；这不会删除它，调用方继续原降级路径。整块译文也消失时，不能只补一个 `x` 就把空译文判为成功。只包含原子、没有文字的合法源文可以从空输出恢复原子。

这是按结构与相对位置恢复，不是经过语义对齐证明的精确数学位置。源/目标语序差异很大且没有邻近锚点时，位置仍是近似值；不应把结构合约通过描述为公式语义已完全校对。

## Unicode 与可见字符

实现不调用 `normalize`，不执行 NFKC、NFC、大小写折叠、全角替换或字符重新编码；源文本只读取，译文仅按原始 UTF-16 索引切片并插入源文 token。

`𝑁`、`𝒙`、`ℎ`（U+210E）与 U+1D400–U+1D7FF 数学字母保留原码点；组合音标 `e + U+0301`、肤色修饰符、ZWJ 表情和国旗不会被插入点切开。换行、制表符、NBSP、全角字符也不被归一化。

本函数不能阻止模型自身把 `𝑁` 翻成普通 `N`；它保证后端补位不做这样的字符转换。原始请求/其他生产路径的 Unicode 保留由总集成补充检查。

## 已实现的接线

Core 的 `invoke` 在适配器返回单段且取消信号复验后，先走原有 `validTranslation` 成功路径；校验失败时尝试 `restoreMissingAtoms`。修复成功直接返回最终结果，避免再发严格重试、投影或多个叶子翻译请求；失败则按原策略处理，不能吞掉其他格式错误。

llama.cpp 适配器会返回完整文本，由 Core 校验，因此此接线能保住本地模型刚生成的译文。某些适配器（如 LibreTranslate/custom-http）会先在自己的实现里抛出 `placeholder` 且不返回文本，这种情况没有原始目标可供本函数恢复，本轮纯函数不改变它们的错误协议。

## 远程网关同步恢复

网关 `gateway/server.mjs` 原先会在自己的 `translated()` 内直接丢弃失标译文，扩展 Core 因而拿不到那段原结果。网关版本升为 **0.2.3**，现在先保持已有合法结果的快速路径，再对仅缺原子的结果运行同一算法，最后必须通过原有 `placeholdersMatch` 才能发出成功 NDJSON。没有增加协议字段或透传未校验的原始输出。

`gateway/placeholder-atoms.mjs` 是上述 TypeScript 算法的纯 ESM 转译副本，使用内部同等严格的树匹配完成末尾校验，没有 Node 运行时依赖。它不是人工维护的另一套位置算法：`gateway-atoms-034.test.mjs` 将源文件转译后与该模块 `BEGIN TRANSLATED BACKEND ALGORITHM` 标记之后的函数主体逐字比较。以后改变源算法必须重新转译这一段；内部节点匹配前导不动。TypeScript 仅用作现有开发测试工具，启动网关不需要安装它。

原有 13 组函数合约现在每次同时调用扩展后端与纯 JS 网关实现，逐字符比较结果，覆盖全部非 BMP、字素和不安全结构拒绝情形。新增网关 7 项检查转译防漂移、所有重试责任下缺 `x` 仅一次推理、数学字母/字素透传、纯原子空输出、坏 `g`/额外/重复/不确定标记仍拒绝、批量段 ID 不串，以及实际 `Core → remote-node → gateway handler → 模型响应` 的一次推理恢复。

旧 `caller` / `gateway` 重试责任保持：缺 `g` 等无法安全修复的情况，caller 每次一次推理，旧直接客户端/gateway 仍最多两次。普通文字的空输出仍返回模型错误；只有可完整还原的纯原子源文允许从空输出恢复。网关沿用之前的译文首尾 `trim`，没有新增任何 Unicode 归一化。

最终独立 strict 编译通过；13 项双端函数 + 7 项新网关 + 原网关重试 6 项 + 显式语言 1 项，共 **27/27 通过**。日志：`work/integration-034/atoms-gateway-tests.log`。网关回放执行真实 handler 和 remote/Core 代码，但固定模拟上游响应，不等同于真实远端模型的性能或质量验收。
