# Yi v0.2.13 — 本地优先的网页翻译

用于 Chrome / Edge 的网页翻译扩展，支持双语页面、划词与输入框翻译、图片 OCR、PDF 双栏阅读、YouTube 字幕，以及本地模型和多服务调度。

## 下载与安装

- 普通用户下载 **`translate-ext-0.2.13-chrome.zip`**，解压后在浏览器扩展管理页开启开发者模式，选择“加载解压缩的扩展”，加载直接包含 `manifest.json` 的文件夹。无需安装 Node.js。
- Windows x64 用户如需本地翻译模型，再下载 **`yi-local-setup-0.2.13-windows-x64.zip`**，解压后运行 `setup.cmd`，按提示提供扩展 ID。首次运行会下载模型和运行库，建议预留 5 GB 磁盘空间。安装不会自动开启开机自启。
- 两个 **`.sha256`** 文件用于校验对应附件。具体 SHA-256 以本次 Release 实际附件为准。
- GitHub 自动提供的 **Source code** 压缩包是源码，需要构建后才能加载。首次使用 OCR、对齐或浏览器内置翻译时还可能下载相应模型或语言包。

已有用户将新版解压到原来的固定目录后，在扩展管理页重新加载并刷新网页。

## 本版更新

- 减少重复服务检测，检测请求不再污染正文翻译速度、成功率和调度排名。
- 修复扫描 PDF 的失败计数，增加页级重试；存在失败页时不自动打印不完整的译文。
- 图片和 PDF 任务支持实际取消，关闭或切换文档后隔离迟到的结果并释放资源。
- PDF 一次上传与解析后逐页复用；阅读时按可视区域淘汰远页画布，返回已译页时复用译文。
- 改善内置翻译的语言方向、语言包下载状态和短时不可用缓存。
- 服务状态页局部刷新，保留焦点与服务行状态。
- 合并字节相同的 WASM 副本，保留 OCR 与对齐各自需要的运行库；原始验收包比上一版缩小约 31%。
- 提供独立 Windows x64 本地模型安装工具、构建编号和交付文件完整性校验。

## 验证与范围

0.2.13 原始功能验收通过 **834 项后端测试、44 项界面测试**，以及正式后台、语言包、OCR/PDF 和本地对齐模型专项。翻译接口集成使用本机 HTTP 回放，不代表全部云端服务或硬件环境均经过实测。

公开前已在 Windows + Edge 的新目录从拟公开源码独立安装依赖，完成构建、837 项后端和 44 项界面测试，以及正式包浏览器联调和 ZIP 校验。新增 3 项为源码打包测试；详见 [发布准备记录](PUBLISH-PREP-0.2.13.md)。本轮没有重跑真实 OCR / 对齐权重专项。

复杂 PDF、较差的扫描图像和词句对齐仍可能出现误差。浏览器内置翻译取决于浏览器、系统和语言包支持；独立本地模型安装工具仅支持 Windows x64。

项目自有代码采用 **MIT**。第三方组件、模型和运行库保留各自许可证。启用云端翻译或远程对齐后，相关文字会发送给对应服务；本地优先不等于所有配置都离线。
