- 重写 README，区分普通安装、可选本地模型和源码构建；新增发布说明及发布步骤。MIT 许可保持不变，第三方原始许可、版权和词典来源未被删改。

## 源码导出

新增 npm run zip:source。工具在临时目录使用 Git 解释根目录与嵌套 .gitignore，不改动项目的 Git 状态，也不采用开发机全局忽略规则。漏排除模型或环境文件、源码链接、越界路径、过大文件会中止；输出 ZIP / 校验文件也不能指向目录、链接或其他特殊文件。

生成 .output/translate-ext-0.2.13-source.zip 及 .sha256。包内 SOURCE-MANIFEST.json 列出每个源文件的相对路径、大小和 SHA-256。完整 public/dict/ 和 public/licenses/ 保留；public/assets/ 由构建重新生成。建立 GitHub 仓库时提交展开的源文件，不用一个大 ZIP 代替源码历史。

普通安装与 npm ci / npm run build 不要求 Git；源码导出及包含其回归的后端 / 完整测试需要 Git。
