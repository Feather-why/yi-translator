# 0.2.13 全面优化与验收

日期：2026-11-04。用户明确授权本轮同时修改前后端，并选择项目自有代码采用 MIT。未发布 GitHub 或扩展商城。

## 1. 服务检测与统计

自动健康检查仅调用适配器的 health；没有健康端点时跳过，不再偷偷试译。手动检测保留真实测试请求、实际用量和错误状态，但不计入正文翻译 P50、EWMA 或成功率，避免测试按钮改变调度排名。状态页不再一次触发两套重复检测。

providers:test 可指定 sourceLang/targetLang；未给时兼容旧调用。测试样例覆盖 20 种语言，欢迎页自动检测仍不会弹出语言包准备页。

## 2. 扫描 PDF 失败与重试

扫描页分别记录总量、成功、失败和保留内容；整页 OCR/翻译异常会变成可见失败，支持按页重试。打印准备中遇到未完成或失败页时停止，不把含遗漏的版本当作完成后自动打印。补齐初始零计数字段。

## 3. 媒体取消与生命周期

图片每次打开有独立代际，所有异步回包先确认仍属当前状态，关闭后不会污染新打开的覆盖层。requestId 对应真实可取消任务，按扩展 ID、tab/frame/document 隔离。共享 OCR 只在最后一个订阅者取消时中止；队列任务立即移除，活动推理容器会销毁。

PDF 换文档会中止任务、断开专用翻译端口、移除监听器/观察器/定时器、取消渲染、销毁 PDF.js 文档和后端句柄。页面级划词 UI 保留为一个共享实例，避免每开一次文件重复注册。

## 4. 内置翻译语言方向与缓存

不可用缓存只针对真实语言对，TTL 15 秒；auto 先识别语言。显式检测、语言包准备完成后失效相关状态。下载期间锁定方向，捕获本次源/目标语言；迟到的检测或刷新结果不能覆盖用户新选择。适配器版本更新到 1.0.2。

## 5. 长 PDF 性能

前端通过 pdf:open 上传一次，后续扫描页只传 documentHandle 和页号；后端复用字节、文档摘要和 PDF.js 解析。最多驻留 3 份文档，原始 PDF 字节总量 64 MiB，单文件仍限 25 MiB，闲置 5 分钟释放。64 MiB 是输入字节上限，不能等同于整个浏览器的内存上限。关闭文档会取消对应提取/翻译；worker 重启或会话过期时前端透明重开一次。

可靠的书签可直接确定参考文献区间；没有可靠书签时扫描阅读页之前的前缀并缓存，不再为第一页无条件扫描全本。第一次直接跳到后页仍可能读取前面的文字层。

阅读时以最多 8 页、2400 万总画布像素为淘汰目标，优先保留可视和正在处理页。离屏画布淘汰后保留译文数据和计数，返回该页时本地重画，不重新调用翻译。打印期间暂时保留全本画布，结束或取消后恢复淘汰；打印大型文档仍可能占较多内存。

## 6. 服务状态界面

复用已有服务行、按钮和表格，仅更新变动内容；排名移动后保留焦点，暂停/恢复按钮对应的动作也会更新。停用服务仍不进入表格，精确表不展示高速排名。

## 7. 构建资源与许可

ONNX 资源只准备所需的四个运行文件；构建结束按 SHA-256 找到完全相同的 WASM 副本，把真实 JS 引用重定向到同版本本地文件后去重。OCR 与对齐模型用的两套不同 ONNX 版本各自保留，未把它们互相替换。

项目自有代码采用 MIT；第三方 LICENSE/NOTICE 继续随扩展保留。模型、CUDA、浏览器语言包不重新许可。新增 docs/PRIVACY.md，说明本地/云端翻译、模型下载、存储、同步、规则订阅和助手的数据流。

## 8. 独立安装与发布验收

新增 Windows x64 companion ZIP；无需源码或 Node.js，setup.cmd 读取扩展 ID，自动选择满足条件的 CUDA 13.4 或 CPU，下载固定 llama.cpp b12069 和固定 revision 的 Hy-MT2 Q4_K_M，逐项校验大小与 SHA-256。下载、运行库部署、模型健康检查、助手注册按顺序进行，开机自启默认不开。

断点需有匹配的归属记录。运行库切换使用受文件清单保护的目录，不覆盖用户增改文件；旧版本保留为 previous-* 以便恢复。工具不支持非 Windows x64 平台。安装流程采用离线夹具验证，未在本机重新下载大模型或替换日常 8081 服务；不能据此保证所有朋友的驱动/硬件都兼容。

版本来自 package.json；build-info.json 和 ping.buildId 标识构建源摘要。release-integrity.json 记录每个交付文件大小与 SHA-256；正式目录、ZIP 和内外版本一致性均检查。npm run verify:release 串联类型检查、后端合约、前端 UI、正式包构建、真实后台浏览器回归和安装包校验。设置 OCR_MODEL_CACHE / ALIGN_MODEL_CACHE 后加入缓存权重的真实模型验证；不自动下载权重。

原 run-local.ps1 参数、默认端口、日志路径、/health 与 Q4_K_M 模型 SHA 未更改。新增安装工具参数和卸载步骤见 LOCAL-INSTALLER.md。

## 协议兼容

PROTOCOL_VERSION 为 3。本轮增量：providers:test 两个可选方向字段；ocr:image/pdf:translate 可选 requestId；pdf:translate 可选 documentHandle；media:cancel、pdf:open、pdf:close；capabilities.media.cancel/pdfSessions 可选；ping.buildId 可选。旧调用方式保留，前端根据能力选择旧后端逐页路径。

会话失效固定返回 bad_input / retryable=true /「PDF 会话已失效，请重新打开文档」。requestId 为 1–128 个 A–Z/a–z/0–9/._:-；有 ID 在途任务最多 64 个；取消墓碑最多 256 项/30 秒，解决取消先于任务登记到达的竞态。

## 验证边界

正式翻译集成使用本机确定性 HTTP 回放验证调度、流式输出、占位符、计数、取消、重试及 UI；不消耗云端服务额度，也不是本轮对 Hy-MT 翻译质量或每秒生成速度的评测。OCR 与划词对齐另用本机缓存的真实权重验证优化后的正式包，外网下载被拦截。浏览器语言包下载状态使用浏览器 API 回放，不宣称在所有 Chrome/Edge 版本与语言对上实测可用。
