# Yi 0.2.16

改善图片密集页面、长文章和综合模式批量更新译文时的响应。

- 网页持续刷新图表、编辑器或广告区域时，翻译器能及时发现同屏新增或修改的正文。多层菜单展开、文档含大量小节导航时，减少重复的祖先查找和范围判断。
- 综合模式收到最终译文后由浏览器统一排版，每帧只画最新进度。大量结果一起到达时优先显示完整译文，在部分段落上保留过渡动画。
- 超长正文和深层行内标签使用连续区间记录字符位置。长段落的逐句译文分批插入，读者可以在插入期间点击、切换模式或还原页面。
- 密集图库只定位可见覆盖层，大 OCR 框取色和临时 JPEG 图片读取占用主线程的时间减少。图片换源会清理旧结果；图库隐藏后卸载也会释放覆盖层。

下载 `translate-ext-0.2.16-chrome.zip` 并解压到原扩展目录，在浏览器扩展管理页重新加载，再刷新正在阅读的网页。详细数据见[交接文档第 53 节](HANDOFF-BACKEND.md#53-长正文图片及综合模式的页面卡顿)。
