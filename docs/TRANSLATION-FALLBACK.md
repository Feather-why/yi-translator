# 高速档内置翻译与可选网页兜底

当前版本：扩展 0.2.2，后台 `0.2.2-alignment`，协议仍为 v2。这次未新增公共 RPC 或运行时依赖。

## 调度顺序

| 顺位 | 快速档 | 精确档 |
|---|---|---|
| 1 | 已启用且语言包已准备的浏览器内置 Translator | 参与精确档的原有官方服务 |
| 2 | 已配置且仍有预算的原有官方服务 | 已连接的本地模型 |
| 3 | 已连接的本地模型 | 浏览器内置 Translator 已可用的语言对 |
| 4 | 用户明确设置零免费预算的其他官方服务；显式置顶仍沿用原有行为 | 同左 |
| 5 | 用户主动开启的 Google 网页接口，仅参与快速档 | 不参与 |

按最新第 21 节建议，高速档默认先用本机内置翻译，减少云端字符消耗；官方服务的显式手动置顶仍优先。某次请求遇到账户额度不足、接口拒绝、未准备语言包、模型未启动或服务超时，会在同一次请求继续尝试后备。预算在发请求前预留，剩余额度不足的请求不会超发。用户暂停或停用的服务不会自动开启。本地服务虽默认归精确档，也能接住快速档的额度耗尽；内置服务虽显示在高速档，也能作为精确档的最后一个本机后备。

前台对冲只在同一顺位内执行，不能因为等待 300ms 就提前发送给非官方接口或抢先使用本机后备。页面粘性不能跨越默认服务顺位；恢复可用的内置或额度服务不会被上一轮更低顺位的后备抢占。Google 即使置顶，仍然排在可用官方和本机服务之后；旧 Google 缓存也不能绕过关闭开关或覆盖更高顺位可用服务。

这些规则保证有后备服务可用时请求继续进行。所有服务都不可用时会返回真实错误；不会显示假译文，也不能保证断网且本机模型关闭时仍能翻译。

## 准备浏览器内置翻译

在设置的「翻译服务」中选择「浏览器内置翻译（Chrome / Edge）」。它默认启用，位于高速档，无云端字符额度。默认只有经过真实能力检查、语言包已准备的请求才会使用。

点击「保存并测试」时，如果语言包可以下载但尚未就绪，会打开本扩展的可见准备页。点击「下载并启用翻译语言包」，需要自动识别时再点击「准备自动识别语言」。准备页允许修改语言代码，如 en、zh、zh-Hant、ja。下载成功后关闭准备页并重新测试即可。

准备页位于后端负责的 offscreen 入口；可见准备页不会注册隐藏 offscreen 的内部消息监听器。真正的翻译在本机隐藏 Window 中执行，由 service worker 的桥接传入请求，支持取消、超时、会话回收，不向网站注入执行代码。

Chrome / Edge 的 `Translator` 是 Window API，不能在 service worker 中直接调用。首次下载要求目标 Window 内真实用户操作；后台请求不能伪造这个操作，所以自动健康探测绝不打开准备页或静默下载。自动识别优先使用后台 chrome.i18n.detectLanguage 的真实 CLD，要求可靠且主语言至少 90%、其他语言低于 10%；没有该 API 时才使用已准备的原生 LanguageDetector。识别不可靠或混语时直接交给其他服务，不猜成英语。

来源与设备实测见 [BROWSER-TRANSLATOR.md](BROWSER-TRANSLATOR.md)。各浏览器、语言包、设备的支持情况以运行时检查为准。

## Google 网页接口

Google 网页翻译位于独立「非官方」分组，默认关闭。需要时在设置中主动启用并保存；不需要时关掉即可。该操作同时维护已有的 `settings.core.allowUnofficial` 全局开关。保留现有非官方标记，不添加额外设置项。

适配器位于 `src/backend/providers/unofficial/google-web.ts`。固定请求 `https://translate.googleapis.com/translate_a/single`，不使用用户的 Google Cookie、浏览器登录态或账户密钥；不切换域名、轮换代理、自动处理验证码或突破上游限制。这是网页接口，不是 Google Cloud Translation 正式开发 API，没有公开的开发协议、免费额度或稳定性承诺。

固定限制：同时一次请求、每次一段、最多 1000 个 UTF-16 字符、相邻实际请求至少间隔 5 秒、默认超时 8 秒、最低调度权重。设置页不提供提高并发、QPS、权重或改端点的选项；可缩小单次片段及调整超时。

收到 HTTP 429 时立即持久化暂停。扩展重启、定时健康检查或经过一段时间都不会自行再次请求。稍后由用户在状态页明确「恢复」，才重新参与。关闭服务不会清理用户译文记忆；普通 Google 自动缓存在关闭时也不会复用。

带链接、原子和嵌套占位符仍走同一严格校验；内置和网页接口失标时也可采用已有整句翻译后恢复格式的路径，而不是直接牺牲语序。无法可靠恢复时保留安全降级和换服务。

## 验证

后端回归覆盖：已开启内置优先且不消耗云端额度、内置不可用→预算用尽→本地成功、内置成功不请求本地/网页、精确档本地优先、跨组不对冲、粘性不抢占恢复额度、默认关闭/显式启用/全局关闭、429 持久暂停/重启不重试/手动恢复、旧缓存门控、准备页只由显式测试打开、API 根本不支持时不打开无效准备页。

Google 解析测试回放本机实际访问收到的响应结构。2026-11-03 单条公开句 `Phonetics mainly concerns speech sounds.` 的实际接口返回 HTTP 200、译文「语音学主要涉及语音。」；只做功能样例，不用于证明接口长期稳定或评估吞吐。429 使用回放验证，测试不会为制造 429 而反复请求实际接口。
