# Yi 0.2.15

本版改善动态网页翻译时的操作响应。网页一次加入很多条目时，扩展分批识别和插入译文，优先处理视口里的文字。翻译过程中仍可点击页面按钮、滚动，或随时还原原文。

- 列表复用同一个段落时会跟随新内容。同文重绘可以沿用已有译文，网页更换链接或代码时会更新译文里对应的内容。
- 预渲染的隐藏菜单展开后可以翻译，聊天区域从空文本开始逐字写入也能被识别。单页应用整体更换页面主体时，翻译会接着处理新页面。
- 打开「只翻正文」时，多层文章容器里的同一段文字只计算一次。播放器频繁替换按钮和字幕容器时，会合并处理更新，并继续翻译新的字幕。

**安装或更新**　下载 `translate-ext-0.2.15-chrome.zip`，解压到用于加载扩展的固定文件夹，在 Chrome 或 Edge 的扩展管理页重新加载，再刷新网页。已有的本地模型可继续使用。

实际测试场景、测量条件和范围见[交接文档第 52 节](HANDOFF-BACKEND.md#52-动态网页交互与性能回归)。
